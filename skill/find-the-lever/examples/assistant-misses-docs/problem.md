# "The assistant can't find my doc"

**Who:** Knowledge workers using the in-product assistant to answer questions from their connected work sources.
**Trying to:** Get a quick answer or summary from a document they know exists, usually one they're actively working on.
**Going wrong:** "No answer" responses have risen and users say it can't find their documents. Return rate is falling.
**Value if fixed:** Users get answers from today's work without opening the doc, and trust the assistant enough to keep asking.
**Success signal:** No-answer rate back under 10% (now ~15%); next-week return rate back to 58% (now 51%).
**Stakes:** Medium. Fixes are reversible, but lost trust is slow to win back.
**Out of scope:** Answer quality once the right doc is found.
